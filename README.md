# Eksperimen_Tekanan_Hidrostatis-Simulasi_Fluida-Dinamis-
Percobaan ini dirancang dalam bentuk simulasi interaktif pada sebuah halaman web. Peserta didik mengamati sebuah tangki berisi cairan yang dilengkapi sensor tekanan. Sensor dapat digeser ke berbagai kedalaman untuk mengukur tekanan pada titik tertentu.
